# fake-siri

呼びかけると質問を聞き取り、Codexの回答をVOICEVOXで読み上げるWindows用の常駐アプリです。画面・ショートカットの名前は「チャッピー」です。

待ち受け・文字起こし・読み上げはPC内で処理し、回答文の生成にChatGPTログインによるCodexの利用枠を使います。OpenAI・Apple・VOICEVOXの公式アプリではありません。

```text
呼びかけ → Voskで検知 → ポロン♪ → 質問を録音
        → faster-whisperで文字起こし → Codexで回答 → VOICEVOXで読み上げ
```

## 必要なもの

| 項目 | 条件 |
|---|---|
| PC | Windows x64、マイク、スピーカー。開発PCではメモリ16GB・CPUのみで動作確認 |
| Python | 3.12の64bit版。`py -3.12 --version` で確認 |
| Codex | ChatGPTログインと、選択モデルを利用できるCodexの利用枠。APIキー認証は非対応 |
| VOICEVOX | Windows版の音声エンジン。以下の手順で別途導入 |

初回のライブラリ・モデル取得と、Codexによる回答にはインターネット接続が必要です。音声モデルなどを保存するディスクの空き容量も確保してください。別PCでの初回導入と長時間運転はまだ検証中です。

## 導入する

### 1. PythonとCodexを準備する

[Python公式のWindows向け配布](https://www.python.org/downloads/windows/)からPython 3.12の64bit版とPython Launcherを導入してください。既にPython 3.12を利用できる場合は再導入不要です。

Codex未導入の場合は[公式のWindows向け手順](https://learn.chatgpt.com/docs/cli#getting-started)で導入し、新しく開いたPowerShellで次を実行します。[認証方法](https://learn.chatgpt.com/docs/auth)はChatGPTを選んでください。

```powershell
codex login
codex login status
```

このアプリ自身は、セットアップで導入する[公式Python SDK](https://learn.chatgpt.com/docs/codex-sdk#python-library)付属のCodexランタイムを使います。ログイン情報をリポジトリへコピーする必要はありません。

### 2. VOICEVOXを導入する

1. [VOICEVOX公式サイト](https://voicevox.hiroshiba.jp/)からWindows版をダウンロードします。CPU版で利用できます。
2. インストーラー版はVOICEVOXを一度起動し、案内に従って音声エンジンをダウンロードしてください。ZIP版は展開して利用します。詳細は[公式の導入手順](https://voicevox.hiroshiba.jp/how_to_use/#音声合成エンジンのダウンロード)を参照してください。
3. VOICEVOX単体で文章を再生できることを確認し、エディターを終了します。fake-siriが必要なときにエンジンを起動します。

自動検出するのは、WinGetの標準導入先と、`%LOCALAPPDATA%/Programs/VOICEVOX`・`%ProgramFiles%/VOICEVOX` 内の `vv-engine/run.exe` です。別の場所や別の構成に導入した場合は、実際の音声エンジンの `run.exe` を指定してください。`VOICEVOX.exe` はエディターなので指定しません。

リポジトリ直下の `config.local.json` に、例えば次の設定を保存します。`D:/Apps/...` は自分の導入先へ置き換えてください。既にファイルがある場合は、他の設定を残して `voicevox.engine_path` だけを変更します。

```json
{
  "voicevox": {
    "engine_path": "D:/Apps/VOICEVOX/vv-engine/run.exe"
  }
}
```

初回ダウンロード型のインストーラーでは、エンジンがエディターとは別の場所に保存される場合があります。場所を特定できなければ、CPUのZIP版を任意の場所に展開し、その中の `vv-engine/run.exe` を指定してください。

### 3. fake-siriを準備する

このリポジトリをCloneするか「Code → Download ZIP」で取得し、書き込み可能なフォルダーへ展開してください。ZIPの中から直接起動せず、展開したフォルダーの `setup.cmd` を開きます。

セットアップは専用の `.venv`、固定バージョンのPython依存関係、日本語モデルを準備し、デスクトップとスタートメニューに「チャッピー」を作成します。モデルは初回に取得し、設定済みのモデルは再利用します。

### 4. 接続を確認して起動する

このフォルダーでPowerShellを開き、次を実行します。

```powershell
.venv/Scripts/python.exe -m fake_siri --doctor
```

モデルの存在、VOICEVOXの接続と声ID、CodexのChatGPT認証、音声デバイスを確認します。AIへ質問は送りません。確認のために起動したVOICEVOXは終了時に停止します。

問題がなければ「チャッピー」を開きます。画面が「待ち受け中」になれば利用できます。マイク・スピーカーは「設定」で選べます。アイコンがない場合は `install-shortcuts.cmd`、直接起動する場合は `start.cmd` を使ってください。

## 話しかける

1. 既定の呼びかけ語「ニセモノ」を言い、開始の「ポロン」が終わってから質問します。合図の再生中は録音しません。
2. 回答後、12秒以内なら呼びかけなしで続けて質問できます。時間切れで終了の合図を鳴らし、呼びかけ待ちに戻ります。「おしまい」でも戻れます。
3. ウィンドウの×は通知領域へ隠す操作です。終了するには通知領域のアイコンを右クリックして「終了」、または `stop.cmd` を開きます。

画面下から文字で質問することもできます。「応答を中断」で録音・回答・再生を中断します。読み上げ中の声による割り込みは未対応です。

VOICEVOXは最初の質問で起動し、最後の回答が終わってから30分間会話がなければ停止します。通常のアプリ終了時にも停止します。既に別途起動していたサーバーは停止対象外です。休止後の最初の回答は起動待ちが加わります。

呼びかけ語は複数登録でき、声・待ち時間・Codexモデルも変更できます。[設定方法と文字起こしの差し替え](Docs/configuration.md)を参照してください。

## 通信・保存・利用枠

- 既定構成では録音をクラウドへ送らず、文字起こしした質問と会話の文脈をCodexへ送ります。Web検索が有効な場合は回答生成に検索も使います。
- 通常の録音と会話表示はメモリ内で扱います。外部文字起こしの一時WAVは処理後に削除します。エラーや導入先を含み得るログ・診断音声は `trash/` に保存するため、公開前に内容を確認してください。Codex側の認証・ログはCodexの設定に従います。
- APIキーでは送信せず、送信前にCodexの利用枠を確認します。追加クレジットの購入や課金APIへの切り替えはしません。アカウント側の追加クレジット設定は変更しないため、課金を避けたい場合はCodex側でも設定を確認してください。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 起動・モデル準備に失敗 | Python 3.12、インターネット接続、フォルダーの書き込み権限。`setup.cmd` を再実行 |
| VOICEVOXが見つからない | エンジンの追加ダウンロードと `engine_path`。`--doctor` で接続・声IDを確認 |
| 声を拾わない・認識が違う | Windowsのマイク権限、設定した入力機器、周囲の雑音。「今すぐ話す」で呼びかけ検知を省いて確認 |
| Codexが使えない | `codex login status`、利用枠、インターネット接続。モデルが使えない場合は「設定」で自分のアカウントで利用できるモデルへ変更 |

PCのスリープ中は待ち受けできません。詳しい検証方法は[開発・検証](Docs/development.md)を参照してください。
