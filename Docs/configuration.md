# 設定

初回導入と基本操作は[README](../README.md)を参照してください。

## 設定の保存先

共通の既定値は `config.json`、このPCだけの変更はGit対象外の `config.local.json` です。設定画面から保存すると後者を更新し、接続し直します。

手動で変更するときはアプリを終了し、変更する項目だけを `config.local.json` に書いてください。既存の項目があれば残します。パスは `/` 区切りで指定できます。相対パスはリポジトリ直下を基準に解決します。

別PCへ渡すときは自分の `config.local.json` を含めず、相手のPCでセットアップしてください。USB機器の番号や導入先はPCによって異なります。

## 呼びかけ語と合図

設定画面の一覧で語を「追加」「選択を削除」できます。どれか1つに一致すれば反応し、先頭の語を案内に表示します。

かな・カナ・全角半角をそろえ、空白・句読点・長音記号を除いて比較します。漢字は読みへ変換しないため、既定では「ニセモノ」「偽物」「偽者」を登録しています。認識結果に登録語を含むかで判定するので、「これは偽物だ」のような普通の発言でも反応します。

「開始・終了を音で知らせる」をオンにすると、開始は上がる2音、追加質問待ちの時間切れは下がる2音が鳴ります。どちらも約0.44秒の保存済みWAVで、VOICEVOX停止中でも再生できます。オフにすると呼びかけから続けて質問できます。

## 声・待ち時間・モデル

| 項目 | 設定場所と意味 |
|---|---|
| 声・速さ | 画面の声ID・話す速さ。音声ごとの利用条件は[第三者の利用条件](../THIRD_PARTY_NOTICES.md)を参照 |
| 会話の待ち時間 | 画面の「続けて話せる秒数」「VOICEVOX休止（分）」 |
| Codex | 画面のモデル名。既定は `gpt-6-luna`。利用可否はアカウントによる。空欄ならCodexの既定モデル |
| 詳細設定 | `audio` の無音判定・最大録音時間、`codex.style` の話し方、`codex.web_search` の検索設定など |

通常は0.9秒の無音で録音を終え、最大25秒まで録音します。話し始める前の無音は6秒まで待ちます。

VOICEVOXの接続先は既定で `http://127.0.0.1:50121` です。PC内のHTTP接続のみ許可します。別途起動したエンジンを使うなら、接続先をそのポートに合わせ、`voicevox.auto_start` を `false` にします。そのエンジンの起動・終了は利用者が管理します。

## 文字起こしを差し替える

既定はCPUで動作するfaster-whisperのsmallモデルです。モデル名を変える場合は `transcription.model_path` を空文字に戻して `setup.cmd` を再実行します。既存のモデルを指定した場合はそのパスを維持し、自動で別モデルへ置き換えません。

別のプログラムを使う例です。パスを自分のプログラムに置き換え、`config.local.json` の他の項目を残して追加してください。

```json
{
  "transcription": {
    "backend": "command",
    "command": ["D:/Tools/python.exe", "D:/Tools/transcribe.py", "{audio}"],
    "timeout_seconds": 60
  }
}
```

プログラムには16 kHz・モノラルのWAVパスを渡します。認識した本文だけをUTF-8で標準出力に返し、ログは標準エラーへ出してください。終了コード0を成功と扱い、一時WAVは処理後に削除します。シェルを介さず引数の配列で起動します。外部プログラムがクラウドへ送信する場合、その通信や料金はプログラム側の仕様に従います。
